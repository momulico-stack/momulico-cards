# 오늘의 영화 TMI (시리즈)

기준작: 1. 이소룡 차차차 (2026-11-09). 한 장짜리.

- 좌상단: 번호 `N.` (40px, 흰 75%) → 제목 "오늘의 / 영화 [TMI]" (84px 800, TMI는 브랜드 초록 솔리드 박스에 흰 글자)
- 본문: 좌측, 폭 640px, 31px, 양쪽 정렬. 첫 글자 드롭캡(흰, 112px, 3줄 높이). 마지막 짧은 줄만 혼자 남기기(orphan). 글자 전부 흰색.
- 인물 누끼 2~3장을 스크랩 스티커(흰 테두리, ±4~6°)로 배치. 우상단·우중단·좌하단 삼각 구도.
- 검정 배경, 로고 고정. 문체: 존댓말 평서("~입니다/~합니다").
- 피드 글: 한 줄 펀치라인 + 해시태그.
