# 심플 아티클형 (Simple Article)

기준작: 2026-11-08 「영화판 현피」(6장). 이 폴더의 `hyunpi/spec.json`이 원본 스펙이다.

## 구성
- 1장 표지 `split_cover`: 풀블리드 인물 사진(그레인) + 중앙 거대한 두 글자 제목(간격 두고 좌·우) + 위에 작은 흰색 머리말. 우하단에 밈 스티커 1개(선택).
- 2장~ 본문 `mag`: 카드 1장 = 사건 1개.
  - 상단 2/3: 콜라주 오버레이(PNG) — 인물은 누끼+그레인+촘촘한 종이 스크랩 테두리, 장면 스틸·포스터는 기울이지 않고 그림자만. 여러 장이면 삼각형 구도, 가려지는 사진 없게.
  - 하단 1/3(top 850): 초록 2px 줄 → 키커 `연도 · 인물` (초록 24px) → 헤드라인 2줄(47px, 800) → 잡지식 2단 본문(29px, 양쪽정렬, 오른쪽 단은 헤드라인 높이에서 시작, 얇은 세로선).
  - 손글씨 메모(`notes`, NanumPen) 0~1개로 위트.
- 텍스트 박스에 배경색 채우지 않음. 넘버링·계정명·슬로건 없음. 로고 위치 고정.
- 문체: 기사체 평서문. 사실 확인된 내용만.
- 피드 글: 한 줄 훅 + 해시태그.

## 렌더
```
python3 tools/make_cards.py templates/simple-article/hyunpi/spec.json out/
```
spec 안의 상대 경로는 spec 폴더 기준. 콜라주 오버레이는 `tools/collage.py`(grain, photo, scrap, compose)로 만든다.
